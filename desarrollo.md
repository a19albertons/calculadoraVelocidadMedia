# Desarrollo

---

## Prerequisitos de desarrollo:

- Android studio (Android Studio Quail 2 | 2026.1.2 Patch 1). La más reciente a la hora de redactar esto. No se asegura la ausencia de errores con versiones anteriores.

Después de clonar el repositorio, se tiene que abrir un nuevo proyecto en Android Studio y seleccionar la carpeta de nombre calculadoraVelocidadMedia.

## Compilar la aplicación

El ide proporciona un boton de play en la parte superior derecha que permite compilar y ejecutar la aplicación en un dispositivo físico o virtual. Para ello, se debe tener un dispositivo conectado o un emulador abierto.
